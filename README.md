# 🚀 AI with Jeevan — 90-Day AI/ML Journey

> **90 Days → One Practical AI/ML Skill → Multiple Projects → One Strong Portfolio**

An interactive, mobile-first web experience designed for beginners, engineering students, and aspiring AI/ML engineers to follow a structured roadmap from Python fundamentals to building autonomous AI agents and deploying practical machine learning applications.

---

## 🌟 Core Philosophy

$$\text{Learn} \longrightarrow \text{Practice} \longrightarrow \text{Build} \longrightarrow \text{Track Progress} \longrightarrow \text{Create Portfolio}$$

---

## ✨ Features

- **Daily Learning Cards (Days 1–90)**:
  - 3 Core Questions: *What is it?*, *Why do I need it?*, *Where is it used?*
  - 4 Pillars: **LEARN**, **PRACTICE**, **BUILD**, and **DELIVERABLE / GITHUB**.
  - 3 daily checkboxes with partial progress tracking (`2 / 3 completed`).
- **Interactive Architecture Modals**: Step-by-step visual pipelines for all 9 major projects.
- **Email-Based Authentication**:
  - Secure login/signup keeping every learner's personal progress saved independently.
  - Screen resets cleanly to empty state upon logout.
- **Admin Control Center**:
  - Reserved administrative access with real-time login counts, learner progression table, individual student progress inspection, and CSV export.
- **Live Skill Tracker**:
  - Real-time progress bars and ASCII progression blocks (`████░░░░░░`) calculated across Python, Data Analysis, ML, DL, GenAI, and AI Agents.
- **Search & Filters**:
  - Instant search across all 90 days by topic, algorithm (e.g. *RAG*, *Random Forest*, *CNN*), or day number.
- **9:16 Instagram Story Generator**:
  - Generate and download clean shareable progress cards formatted for Instagram Stories and LinkedIn.
- **Mobile-First Design**:
  - Sticky bottom navigation on mobile (`Home` | `Roadmap` | `Progress` | `Projects`).
  - No horizontal scrolling, high-contrast accessible typography.

## 💻 Tech Stack

- **Frontend**: React 18, TypeScript, Vite

- **Icons**: Lucide React
- **Celebrations**: Canvas-Confetti
- **Deployment**: Vercel ready (includes `vercel.json`)

## 🛠️ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/kjeevankumar/AIML-90-days-challenge-.git

# Navigate into the project directory
cd AIML-90-days-challenge-

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

---

## ☁️ Deployment on Vercel

1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Root Directory: `./`.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Click **Deploy**!
